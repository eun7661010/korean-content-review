# 통합 검사와 편집 결과

작품 원문과 코드·인용을 표시한 뒤 `--modules style`로 결정론적 후보를 얻는다. `--format json` 결과의 위치는 입력 문자 좌표다. 사람이 후보 문맥과 원래 뜻을 확인하고 원문 → 수정문, 이유를 기록한다. 보호 구간에서는 후보도 편집도 만들지 않는다.

기존 fluent-korean 지침은 자동 검사기가 아니므로 비교 보고에서 '기존 0건 → 새 N건'이라는 효과 표현을 사용하지 않는다. 새 규칙 수, 검출 수, 무작위 표본의 검수자 정밀도를 각각 기록한다. HTML·JSON 같은 구조에서는 노출 문자열만 다루고 식별자를 바꾸지 않는다. 접근성 문구도 검사할 수 있지만 원문을 담은 속성은 보호한다.
