# 선택적 맞춤법 검사

기본 실행에는 외부 전송이 없다. `--modules spell`은 보호 구간을 충돌 없는 자리표시자로 가리고 나머지 텍스트를 `https://nara-speller.co.kr/old_speller/results`에 POST한다. 결과의 위치는 원본 문자 좌표로 되돌리며, 자리표시자를 바꾸려는 제안도 억제한다. 응답과 입력의 공백 없는 문자열이 다르면 좌표를 추측하지 않고 청크를 건너뛴다. 서버가 공백·행갈이만 정규화하면 문자 대응으로 복원한다.

문장·문단 경계에서 1,500자 이하로 나눈다. 경계가 없는 긴 문장은 길이 기준으로 나누며 자리표시자는 쪼개지 않는다. CLI 전체 파일·블록이 같은 요청 예산을 공유한다. 기본 최대 20회, 요청 사이 최소 2초, 실패 재시도 없음이다. 연결·응답 해석 실패와 한도 초과는 보고서에 별도 표시한다. 성공 응답 없음은 오류 없음과 다르다.

이 공개 웹 표면에는 무료 이용 범위 제한이 있다. 사용자 주도 저빈도 최종 검수에만 사용하고, 대량·상업 서비스 연결은 공급사 이용 조건을 확인한다. 안내 링크: [이용 안내](https://nara-speller.co.kr/guide/), [검사 화면](https://nara-speller.co.kr/speller/). 웹 응답 파서를 포크한 것이며 공급사의 공식 API 클라이언트나 국립국어원 공식 판정으로 표현하지 않는다.

벤치마크의 후처리 비교는 허용된 공개 글·만료 고전의 가리지 않은 입력에 대해 청크마다 한 번 받은 응답을 두 후처리에 같이 넣는다. 전송 전 보호 효과와 후처리 억제 효과를 혼동하지 않는다. 온라인 요청은 벤치마크에서만 사용하고 테스트는 합성 응답으로 실행한다.
