# 띄어쓰기 구현과 해석

기본 `--spacing strict`는 확실한 범주만 보고하고 `--spacing all`은 나머지 공백 후보도 info로 보고한다. `--spacing repair`는 OCR 공백 복원용으로 범주 필터를 쓰지 않는다. 세 모드 모두 보호 구간을 제외하고 NBSP와 개행을 유지한다.

| 모드 | 용도 | Markdown 보고 형식 | 자동 적용 여부 |
|---|---|---|---|
| strict (기본) | 확실한 범주 검수 | 원문 ±10자 창의 `⟦변경 자리⟧` → 제안 적용 창, 범주·확신도 | 기본 미적용, 통합 CLI `--apply`(별칭 `--write`) / 단독 CLI `--write`에서만 반영 |
| all | 선택적 표기를 포함한 넓은 검수 | strict와 같은 문맥형 Finding 목록 | 기본 미적용, 명시적 적용 옵션에서만 반영 |
| repair | 공백이 사라진 OCR 줄 복원, 범주 필터 없음 | 변경된 줄만 `[line N]` / `전:` / `후:` | 기본 미적용, 명시적 적용 옵션에서 보호 밖 변경만 반영 |

공백 삽입은 `크게⟦⟧연역과` → `크게⟦ ⟧연역과`처럼 빈 자리를 보여 준다. JSON은 기존 Finding 필드를 유지하고 `context_before`, `context_after`를 추가한다. 제안 없는 검토 항목의 `context_after`는 null이다. repair 보고서의 `items[].line_changes`는 원문 줄 번호·전후 문자열을 담으며 JSON Finding에는 범주·확신도·근거도 남긴다.

검수 모드에서 한글이 20자 이상 연속하고 공백이 없는 줄을 세어 보고서 머리에 `공백이 거의 없는 줄 N개 — OCR 복원은 --spacing repair`를 표시한다. 자동으로 repair로 전환하거나 파일에 쓰지 않는다. `--quiet`를 사용하면 발견·변경 없는 파일 항목은 출력하지 않는다.

| rule | strict 보고 조건 |
|---|---|
| spacing-bound-noun | 것·수·때문·만큼·뿐·데·지·등·줄·바·채·척·듯의 NNB 분석이 상위 두 경로에서 일치. 데·지는 장소/용도·시간 경과 문맥도 확인 |
| spacing-unit | 한글 수사+단위 명사. 한 번/한번은 의미가 모호해 명시적 횟수 문맥 외 제외 |
| spacing-particle | 떨어진 조사(J 품사)가 명사에 결합하는 분석 일치 |
| spacing-ending | 떨어진 어미(E 품사)가 용언에 결합하는 분석 일치 |
| spacing-negation | 부정 부사 안과 용언의 분석 일치. 안 되다는 명시적 금지 문맥만 |
| spacing-optional | 보조용언·합성명사·전문용어·기호·영문/숫자 경계·불확실한 분석. all에서만 보고 |

NBSP(U+00A0)는 의도된 묶음일 수 있으므로 일반 공백으로 바꾸라는 제안을 내지 않는다. 형태소 품사 일치도 의미를 완벽하게 판별하지 못한다. strict는 재현율보다 오탐 억제를 우선하므로 올바르지 않은 표현을 놓칠 수 있다. 보호 억제 수는 strict 범주 필터 이전의 전체 Kiwi 후보 기준이다.

기존 `kiwi_space.py`의 줄 단위 처리, `reset_whitespace=False`, 사용자 고유명사 사전, `잖 아`·`찮 아` 후처리를 계승한다. 새 구현은 전체 분석 결과에서 공백 차이만 후보로 만들고 보호 구간과 겹친 후보를 억제한다. 원문 내부 공백을 건드리지 않으며 개행·탭·CR을 교정하지 않는다. strict·all은 문장 단위 처리가 기본이며 모듈의 `sentence=False` 또는 단독 스크립트 `--no-sentence`로 끌 수 있다. repair는 항상 줄 전체를 분석해 `kiwi.space(text, reset_whitespace=False)`의 보호 밖 공백 차이를 제안한다.

모든 후보 메시지는 '형태소 분석 기반 제안'임을 명시한다. Kiwi 상위 두 분석의 점수차를 토큰 수로 정규화하고 `0.60 + 0.35 × (1 − exp(−차이))`로 확신도를 계산한다. 이는 형태소 분석의 상대적 분리를 표시하는 휴리스틱이며 맞춤법 정답 확률이나 검증된 통계 점수가 아니다. 후보 경로가 하나면 0.80을 사용한다.

Kiwi 초기화는 같은 사전별로 재사용한다. 공개 벤치마크는 초기화와 첫 분석을 제외하고 1,000자당 처리 시간을 측정한다. repair는 공백을 복원하지만 잘못 끊긴 행·문단 구조를 재구성하지 않는다. 보호 표시한 지문은 repair에서도 고치지 않는다. 넓은 복원은 전문용어·합성명사에 오분석이 있을 수 있으므로 전후를 검토한 뒤 적용한다.
